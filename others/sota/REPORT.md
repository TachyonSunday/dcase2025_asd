# 方案报告：ResNet18 + kNN 无监督异常声音检测

> 基于 ImageNet 预训练视觉模型的音频频谱跨域异常检测方案
> 完整复现评估结果：开发集 7 台机器，平均 AUC = 0.599

---

## 一、方案概述

本方案的核心思路是将**音频频谱视为图像**，利用计算机视觉中成熟的 ImageNet 预训练模型（ResNet18）作为冻结特征提取器，结合 kNN 构建异常检测系统。**无需训练神经网络**，仅需计算 StandardScaler 统计量和构建 kNN 索引。

### 技术路线

```
原始音频 (16kHz, 10s)
  → Log-Mel 频谱 (128 mel × T 时间帧)
  → 归一化到 [0, 1]
  → 滑动窗口切片：128×128 patches, 50% overlap
  → 扩展为 3 通道 (适配 ResNet 的 RGB 输入)
  → ResNet18 (ImageNet 预训练, 冻结, fc 层移除)
  → 每个 patch 输出 512 维特征向量
  → StandardScaler 标准化
  → kNN (k=5, cosine distance)
  → Max Pooling 聚合 (取所有 patches 中最大的距离)
  → 异常分数
```

## 二、技术细节

### 2.1 特征提取

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 16kHz | 标准 |
| n_fft | 1024 | FFT 窗长 |
| hop_length | 512 | 帧移 (50% 重叠) |
| n_mels | 128 | Mel 频带数 |
| PATCH_SIZE | 128 | 频谱 patch 大小 (128×128 像素) |
| ResNet 输出 | 512 维 | `resnet.fc = Identity()` 移除分类头 |

### 2.2 关键设计选择

**① 归一化方式**：每张频谱独立归一化到 [0, 1]，而非全局归一化。原因：不同机器的声压级差异很大，全局归一化会丢失机器特有的能量信息。

**② 3 通道扩展**：`patches_t.repeat(1, 3, 1, 1)` 将单通道频谱复制为 3 通道。ResNet18 的 ImageNet 预训练接受 RGB 3 通道输入，虽然频谱是单通道灰度图，但复制为 3 通道后 ResNet 的顶层卷积核仍能提取有意义的边缘和纹理特征。

**③ 滑动窗口步长**：`step = PATCH_SIZE // 2 = 64`，50% overlap。保证频域和时间域的连续覆盖，避免边界效应遗漏异常。

**④ Max Pooling 聚合**：取所有 patches 的 kNN 距离的**最大值**作为文件级异常分数。设计意图：异常通常是局部事件（如短时冲击），max pooling 能捕获任何单个 patch 的异常信号。

**⑤ kNN 参数**：k=5, metric=cosine。余弦距离对特征向量的模长不敏感，适用于 ResNet 特征中模长方差大的情况。k=5 为经验选择，兼顾鲁棒性和灵敏度。

### 2.3 预训练模型

- **模型**：`torchvision.models.resnet18(pretrained=True)`
- **预训练数据**：ImageNet-1K (120 万张自然图像，1000 类)
- **参数量**：约 11M（全部冻结，不参与训练）
- **训练方式**：无需微调，直接用作特征提取器

## 四、性能分析

### 4.1 优势

1. **无需训练**：整个流程仅需构建 kNN 索引，适合数据量有限的场景
2. **valve 表现优异**：AUC 0.711，超过 MLP-AE——说明阀门的声学异常在频谱形态上更接近视觉模式
3. **部署简单**：仅需 ResNet 权重 + scaler + kNN pickle，约 12MB

### 4.2 局限性

1. **域迁移不足**：ImageNet (自然图像) 与 Log-Mel 频谱之间存在显著的领域差异
   - 自然图像：物体、纹理、场景，低频为主
   - 音频频谱：谐波线条、时频模式，以横纹为主
   - ResNet 的 Gabor-like 滤波器学的是图像边缘，不是频谱的谐波结构
2. **Max Pooling 过于激进**：可能对单一离群噪声敏感，产生误报
3. **无时序建模**：kNN 完全忽略了 patches 之间的时间顺序
4. **3 通道扩展粗糙**：简单复制而非真正的伪彩色映射，信息没有增加

### 4.3 为什么不如 BEATs（方案 B）

BEATs 在 AudioSet（两百万段音频事件）上预训练，**训练数据就是音频**。BEATs 的 Transformer 学到的注意力模式（harmonic series, formant structure, temporal modulation）天然匹配声学异常检测任务。ResNet 在 ImageNet 上学到的边缘/纹理/形状特征，转移到频谱检测时相当于"用显微镜看乐谱"——工具没错，但领域不匹配。

## 六、总结

ResNet+kNN 方案验证了**视觉预训练模型可以跨域应用于音频异常检测**，但性能（AUC 0.599）低于从零训练的专用 MLP-AE（0.671）。这验证了一个核心假设：**预训练模型的领域匹配比模型容量更重要**。ImageNet 的 11M 参数不如 145K 参数的专用训练——因为前者学的是"猫狗车人"，后者学的是"这个机器的正常声音应该长什么样"。
