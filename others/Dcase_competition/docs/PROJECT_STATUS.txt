----------------------------------------------------------------------
一、项目概述
----------------------------------------------------------------------
复现 DCASE 2025 Task 2 的先进解决方案，核心算法框架为：
  - 特征提取: 基于 AudioSet 预训练 CED-Tiny 提取音频 Embedding (384维)
  - 异常检测: Domain-wise Local Density Normalization (域感知局部密度归一化)
  - 评估指标: AUC_source + AUC_target + pAUC + Official Score Ω (DCASE 2025 官方)

----------------------------------------------------------------------
二、已完成工作
----------------------------------------------------------------------

1. 工程框架搭建 ✅
   - 标准深度学习项目结构 (configs/, models/, utils/, data/)
   - 全局配置文件 (configs/config.yaml)
   - requirements.txt 依赖管理

2. 核心代码实现 ✅ (已重构)

   - dataset.py: AudioAnomalyDataset 类 (Domain-Generalized)
     * librosa 加载音频 → 原始波形 (16kHz 单声道)
     * 训练模式自动过滤仅保留正常样本
     * 双标签系统: anomaly_label (正常/异常) + domain_label (source/target)
     * 从文件名自动解析标签和机器类型
     * 移除 Log-Mel 计算，直接配合 CED-Tiny

   - models/feature_extractor.py: CEDFeatureExtractor
     * Hugging Face 预训练模型 (mispeech/ced-tiny)
     * 音频专用预训练 (AudioSet)，比 ResNet18 更适合
     * 输入: 16kHz 原始波形，无需预计算频谱
     * 输出: 384 维 Embedding (最后两层 Transformer 拼接)
     * 完全冻结模型参数

   - utils/scoring.py: DomainWiseDensityScorer (GenRep)
     * 分域内存库: source_memory_bank + target_memory_bank
     * 局部密度预计算: K_s=16 (源域), K_t=9 (目标域)
     * 密度归一化异常分数: score = min(score_s, score_t)
     * AUC_source, AUC_target, pAUC, Official Score Ω 计算
     * 保留 KNNScorer 用于对比实验

   - extract_features.py: 特征提取主脚本
     * 支持域标签提取和保存
     * 返回 4 元组: embeddings, anomaly_labels, domain_labels, file_paths

   - evaluate.py: DCASE 2025 官方评估脚本
     * 按机器类型分别评估 (7 个机器)
     * 计算 AUC_source, AUC_target, pAUC
     * 计算 Official Score Ω (调和平均数)
     * 输出 CSV + YAML 格式结果
     * 完全对齐 DCASE 2025 官方评估协议

3. 数据准备 ✅
   - download_data.py: 多线程并发下载 + 断点续传 + 自动解压归档
   - check_dataset.py: 数据集完整性校验
   - 7 个数据集全部下载成功 (总计 2.3 GB ZIP → 2.9 GB 解压)

4. 模型重构 ✅ (2026-06-11)
   - ResNet18 → CED-Tiny (音频专用预训练)
   - Log-Mel 频谱图 → 原始波形输入
   - KNN → Domain-wise Local Density Normalization
   - 单一标签 → 双标签 (anomaly + domain)
   - 混合评估 → 按机器类型 + 按域评估
